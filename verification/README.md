# Проверка редизайна NCreate

Дата: 11 октября 2026 года. Проверялся локальный сайт в Chromium через Playwright. Референсы: пять PNG размером 1906×827 из локальной папки пользователя.

## Скриншоты

- `before/` — главная страница и первый экран до изменений, 1920 и 390 px.
- `final/hero-*.png` — Hero на всех восьми целевых ширинах. `hero-reference-viewport.png` снят ровно в размере референса 1906×827.
- `final/slider-*.png`, `final/slider-next-*.png` — начальный и следующий слайды.
- `final/start-*.png` — инструкция с реальным интерфейсом лаунчера.
- `final/requirements-*.png` — открытое модальное окно.
- `final/footer-*.png` — подвал.
- `final/full-1920.png`, `final/full-390.png` — полная страница после появления секций при прокрутке.
- `final/mobile-menu.png`, `final/showcase-*.png`, `final/download-*.png`, `final/community-*.png` — дополнительные состояния и разделы.
- `final/forum-*.png`, `final/login-390.png`, `final/register-390.png` — визуальная проверка сохранённых маршрутов.
- `final/browser-results.json` — результаты автоматического прогона.

Изображения просмотрены после каждой существенной компоновочной правки. Сходство проверялось по положению крупных объектов, ритму отступов, ширине колонок, цветовым полям и поведению на телефоне. Пиксельное совпадение не предполагается для оригинальных персонажей, логотипа, текста и интерфейса NCreate.

## Технические проверки

- `pnpm check`: 6 тестов, TypeScript, ESLint и production build прошли.
- Chromium: 1920×1080, 1440×900, 1366×768, 1024×768, 768×1024, 390×844, 375×812, 360×800 — нет горизонтального переполнения, битых изображений и ошибок консоли.
- Проверены переключение слайда кнопкой и клавиатурой, открытие и закрытие требований клавишей Escape, горизонтальная прокрутка таблицы, мобильное меню, диалог загрузки с тремя файлами, ссылка Hero на EXE и переход на форум.
- `/forum`, `/login`, `/register` открываются без горизонтального переполнения.
- При `prefers-reduced-motion: reduce` карточки галереи видны без анимации появления.
- Собранный сервер `pnpm start` вернул HTTP 200 для `/` и `/forum`; в браузере production-версии переключение слайда сработало без ошибок консоли и переполнения.
- Три файла релиза Launcher 1.0.0 отвечали HTTP 200 при проверке URL.

Ограничения проверки: формы авторизации не отправлялись, чтобы не создавать аккаунты и записи во внешнем сервисе; нативный лаунчер и игра здесь не запускались; тест выполнен в Chromium, а не на физических устройствах; отдельный лабораторный замер Core Web Vitals не проводился. Vite сообщает о крупном клиентском чанке и проигнорированных директивах `use client` в сторонних пакетах, но сборка завершается успешно.

## Запуск

В корне репозитория: `pnpm install`, затем `pnpm dev`. Полная проверка: `pnpm check`.
